# 补充学习计划

> 基于 web3-go 与 ArkHub 的差距分析，制定详细的补充学习路径

---

## 1. 学习阶段划分

### 第一阶段：基础补齐（2 周）

**目标**：补齐 Redis、消息队列、分布式锁等基础组件知识

| 天数 | 主题 | 学习内容 | 产出 |
|------|------|---------|------|
| Day 1 | Redis 基础 | 数据类型、事务、Pipeline | 实现缓存封装 |
| Day 2 | Redis 分布式锁 | RedLock 算法、Lua 脚本 | 实现分布式锁 |
| Day 3 | Redis 缓存策略 | 穿透/击穿/雪崩防护 | 实现缓存防护 |
| Day 4 | RocketMQ 基础 | 生产者、消费者、Topic | 实现消息收发 |
| Day 5 | RocketMQ 高级 | 事务消息、延迟消息、顺序消费 | 实现事务消息 |
| Day 6 | 消息可靠性 | 发送确认、消费幂等、死信队列 | 实现可靠消息 |
| Day 7 | 复习总结 | 整合所学，写博客 | 技术博客 1 篇 |

### 第二阶段：核心攻坚（3 周）

**目标**：掌握高并发系统设计和高级数据结构

| 天数 | 主题 | 学习内容 | 产出 |
|------|------|---------|------|
| Day 8 | Go atomic | CAS、原子读写、内存屏障 | 实现无锁计数器 |
| Day 9 | Disruptor 原理 | 无锁队列、环形缓冲区 | 阅读论文 |
| Day 10 | Disruptor 实现 | 手写简化版 Disruptor | 实现无锁队列 |
| Day 11 | CPU 缓存优化 | 伪共享、缓存行对齐 | 性能对比测试 |
| Day 12 | 红黑树 | 插入、删除、旋转 | 实现红黑树 |
| Day 13 | 跳表 | 插入、查询、删除 | 实现跳表 |
| Day 14 | 复习总结 | 整合所学，写博客 | 技术博客 1 篇 |
| Day 15 | 中位数滤波 | 排序、窗口滑动 | 实现滤波器 |
| Day 16 | Z-Score/IQR | 均值、标准差、分位数 | 实现异常检测 |
| Day 17 | 加权融合 | 权重模型、异常剔除 | 实现行情聚合 |
| Day 18 | 行情聚合 | 整合滤波 + 检测 + 融合 | 完整行情服务 |
| Day 19 | EIP-712 | 结构化数据签名 | 实现价格签名 |
| Day 20 | 预言机机制 | 定时推送、链上验证 | 实现预言机服务 |
| Day 21 | 复习总结 | 整合所学，写博客 | 技术博客 1 篇 |

### 第三阶段：业务深入（2 周）

**目标**：掌握风控、NFT、微服务等业务知识

| 天数 | 主题 | 学习内容 | 产出 |
|------|------|---------|------|
| Day 22 | 异常交易检测 | 规则引擎、多维度检测 | 实现风控规则 |
| Day 23 | 评分模型 | 权重计算、归一化 | 实现评分模型 |
| Day 24 | NFT 稀有度 | 单属性/综合稀有度 | 实现稀有度计算 |
| Day 25 | NFT 热度 | 多维度评分、时间衰减 | 实现热度评分 |
| Day 26 | K8s 基础 | Pod、Service、Deployment | 部署应用到 K8s |
| Day 27 | K8s 高级 | Ingress、ConfigMap、Secret | 配置服务暴露 |
| Day 28 | Nacos 配置 | 服务注册、配置热更新 | 实现配置中心 |
| Day 28 | Prometheus | 指标采集、告警规则 | 实现监控 |
| Day 29 | Grafana | 仪表盘、可视化 | 创建仪表盘 |
| Day 30 | API Gateway | 路由、鉴权、限流 | 实现网关 |
| Day 31 | ELK 日志 | 结构化日志、日志聚合 | 实现日志系统 |
| Day 32 | 复习总结 | 整合所学，写博客 | 技术博客 1 篇 |

### 第四阶段：实战整合（2 周）

**目标**：按阶段实现 ArkHub 各模块

| 天数 | 主题 | 学习内容 | 产出 |
|------|------|---------|------|
| Day 33-35 | 阶段一 | 基础设施 | Docker Compose 启动 |
| Day 36-38 | 阶段二 | 网关层 | API Gateway 可用 |
| Day 39-41 | 阶段三 | 行情聚合 | 模拟行情源运行 |
| Day 42-44 | 阶段四 | 订单撮合 | 撮合引擎可用 |
| Day 45-46 | 阶段五 | 链上链下 | 一致性服务可用 |
| Day 47-48 | 阶段六 | NFT 业务 | NFT 服务可用 |
| Day 49-50 | 阶段七 | 回购统计 | 统计服务可用 |
| Day 51-52 | 阶段八 | 风控服务 | 风控服务可用 |
| Day 53-56 | 整合测试 | 端到端测试 | 完整系统可用 |
