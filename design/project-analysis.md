# 项目分析文档

## 1. 业务背景

### 1.1 Web3 交易市场现状

2024 年全球加密货币市场总市值突破 3 万亿美元，NFT 全年交易额超 150 亿美元，Web3 用户数量已达 5 亿。然而，当前交易市场仍面临以下核心痛点：

| 痛点 | 具体表现 | 影响 |
|------|---------|------|
| **数据不透明** | 行情来源单一，易被操纵 | 用户以不公平价格成交 |
| **撮合延迟高** | 多数平台撮合延迟 50-100ms | 高频交易、套利策略无法执行 |
| **链上链下不一致** | 充值到账慢、提现状态不准 | 用户信任度低，客诉率高 |
| **NFT 估值困难** | 缺乏统一稀有度和热度标准 | NFT 定价混乱，交易效率低 |
| **多链支持慢** | 新增一条链需 1-2 个月 | 错失新兴公链市场机会 |
| **风控滞后** | 异常交易事后发现 | 资金损失无法挽回 |

### 1.2 目标用户与价值主张

**目标用户画像：**
- **机构交易者**：需要低延迟、高吞吐、可编程 API
- **量化团队**：需要可靠行情数据、毫秒级撮合、风控保障
- **NFT 投资者**：需要准确的稀有度评估、热度追踪、异常交易提示
- **平台运营方**：需要快速扩展新链、灵活配置费率、实时风控

**ArkHub 价值主张：**
> 提供"现货 + 合约 + NFT"全链路交易能力，以自研高性能撮合引擎为核心，以链上链下强一致性为保障，以实时风控为护盾，打造下一代综合数字资产金融平台。

### 1.3 市场机会

| 维度 | 数据 | 机会 |
|------|------|------|
| 全球加密货币用户 | 5 亿+，年增长率 15% | 增量市场巨大 |
| NFT 日均交易额 | 3000 万美元+ | 资产类别持续扩展 |
| 机构入场比例 | 从 5% 提升至 20% | 对合规和性能要求更高 |
| 多链生态数量 | 100+ 条活跃公链 | 跨链聚合是刚需 |

## 技术栈总览

| 技术领域 | 具体技术 | 用途说明 |
|---------|---------|---------|
| **开发语言** | Go | 主后端服务开发 |
| **数据存储** | PostgreSQL / AWS DynamoDB (PDB) | 订单、交易、回购统计等业务数据持久化 |
| **缓存** | Redis | 热点数据缓存、预聚合结果、稀有度计算结果 |
| **消息队列** | RocketMQ | 指数/标记/预言机价格推送、异步上链交易 |
| **实时计算** | Spark Streaming | 交易风控模型、异常交易实时甄别 |
| **注册/配置中心** | Nacos | 多源行情配置热更新、ChannelConfig 动态管理 |
| **通信协议** | WebSocket | 行情实时推送、热点 NFT 推送、保活机制 |
| **区块链** | Ethereum (EVM) 及多链 | 合约交互、事件监听、链上数据校验 |
| **签名标准** | EIP-712 | 预言机价格链上可信签名 |
| **容器化** | Docker / Docker Compose | 服务部署与环境隔离 |
| **并发框架** | Disruptor | 无锁环形队列，高并发订单处理 |

## 核心业务流程

| 业务模块 | 流程步骤 | 关键技术点 |
|---------|---------|-----------|
| **行情聚合** | 1. 接入 14 家异构交易所 + 平台现货价格  <br> 2. 中位数滤波 + 异常剔除算法清洗数据  <br> 3. 按权重融合计算指数价格  <br> 4. EIP-712 签名后通过 RocketMQ 推送预言机价格 | ChannelConfig 统一配置、Nacos 热更新、WebSocket 保活、价格限幅 |
| **订单撮合** | 1. Disruptor 无锁队列接收订单  <br> 2. 内存数据库构建订单簿  <br> 3. 价格优先、时间优先撮合  <br> 4. 极端行情触发熔断降级 | 内存订单簿、自动熔断、百万级吞吐 |
| **链上链下一致性** | 1. 核心业务操作前实时调用公链 API 校验状态  <br> 2. 定时任务异步对比链上链下差异并补偿  <br> 3. 合约事件监听毫秒级同步交易结果 | 双源校验、异步补偿、事件监听 |
| **NFT 业务** | 1. 集成 IPFS 网关拉取元数据  <br> 2. 解析属性并量化稀有度  <br> 3. Spark Streaming 实时计算热度评分  <br> 4. WebSocket 推送热点，Redis 过期键自动下线 | 自定义解析器、稀有度算法、热度评分模型 |
| **回购统计** | 1. 定时任务全量聚合回购数据  <br> 2. 写入 Redis 缓存  <br> 3. 接口直接读取 Redis，故障降级 | 定时预聚合、缓存兜底 |

## 架构特点总结

1. **高并发低延迟**：Disruptor 无锁队列 + 内存订单簿，支撑百万级订单吞吐，撮合延迟仅 10 ms。
2. **抗干扰行情聚合**：14 路异构行情源通过中位数滤波 + 异常剔除算法融合，指数价格精准贴合现货波动。
3. **链上链下强一致**：双源校验 + 异步补偿 + 事件监听三重保障，数据一致性达 100%。
4. **轻量多链扩展**：统一区块链交互 SDK + 策略模式适配，新增公链仅需 2 周。

### 6.3 ArkHub 差异化优势

**1. 全链路整合能力**
- 币安虽然也有现货+合约+NFT，但 NFT 模块与交易模块割裂，数据不互通
- ArkHub 从底层设计上将现货价格作为合约指数价格的锚点，NFT 热度数据反哺风控模型，形成数据闭环

**2. 极致性能**
- 行业平均撮合延迟 50-100ms，ArkHub 通过 Disruptor 无锁队列 + 内存订单簿实现 10ms 延迟
- 百万级 TPS 支撑大促和极端行情

**3. 链上链下强一致**
- 双源校验 + 异步补偿 + 事件监听三重保障，数据一致性达 100%
- 竞品多为"最终一致性"，ArkHub 实现"准实时一致性"

**4. 多链敏捷扩展**
- 统一区块链交互 SDK + 策略模式，新增公链仅需 2 周
- 行业平均 1-2 个月，ArkHub 效率提升 50%+

**5. 智能风控**
- Spark Streaming 实时交易风控模型，异常识别率 88%
- 竞品多为 T+1 或小时级离线风控，ArkHub 实现秒级响应
